# Компьютерное зрение — лабораторные работы

Учебный репозиторий по курсу «Компьютерное зрение» (ИГУ, ФБКИ, 2 курс): от модели формирования
изображения и морфологии «руками» до трекинга объектов, шаблонного поиска и интерактивных демо
на OpenCV.

Половина работ сделана без готовых функций: связные компоненты, свёртка, дилатация, признаки
объектов и классификатор символов реализованы самостоятельно — чтобы понимать, что внутри
`skimage` и `cv2`.

## Что внутри

| Папка | Тема | Ключевые техники |
|---|---|---|
| `numpy_task` | Разминка по NumPy | срезы, оси, маски, broadcasting |
| `formirovanie_izobrazeniy` | Модель формирования изображения | отражение, точечный и рассеянный свет, метрики яркости, контраста (в т.ч. Мишеля), динамического диапазона и пространственной частоты |
| `gradient` | Градиенты | линейная интерполяция цвета между опорными точками |
| `sandbox/test2.py` | Гистограммы | расчёт и визуализация распределения яркости |
| `sandbox/morphology.py` | Морфология | собственная дилатация и сдвиг со структурными элементами |
| `binarnie` | Бинарные изображения | две реализации связных компонент: рекурсивная заливка и union-find |
| `stars` | Подсчёт плюсов и крестов | бинарная морфология `opening` + `label` |
| `wires` | Подсчёт проводов | `opening` с вертикальным структурным элементом |
| `lama_detector` | Детекция объектов | `label`/`regionprops`, локальные признаки, заливка области |
| `sandbox/coins.py` | Монеты | площадь и центроиды через `label` |
| `figures_and_colors` | Фигуры и цвета | `regionprops` + HSV-разбор изображения |
| `alphabet` | Классификатор символов по правилам | число «дырок», вертикальные линии, заливы, эксцентриситет — дерево условий без обучения |
| `vector_recognition` | OCR по признаковому вектору | 11 признаков на символ, классификация по расстоянию до эталонов |
| `aud_25_04` | Анализ контуров | моменты, `approxPolyDP`, выпуклая оболочка, `minAreaRect`, `fitEllipse`, классификация фигур по числу вершин и solidity |
| `opencv_11_04` | Работа с каналами | наложение PNG с альфа-каналом, масштабирование, цветовые преобразования |
| `cat` | Поиск отличий | `absdiff` двух кадров, порог, контуры |
| `motion_detection` | Детекция движения | покадровая разница с веб-камеры |
| `template_matching` | Шаблонный поиск | `matchTemplate`, порог по максимуму корреляции |
| `paper` | «AR» на листе бумаги | поиск четырёхугольника, перспективное преобразование, наложение текста |
| `balls` | Интерактивный трекер шариков | клик по объекту → HSV-маска → морфология → центры и история позиций, настройки в JSON |
| `balls_classify` | Вариант трекера с классификацией | те же маски плюс разбор объектов по форме |
| `falling_ball` | Симуляция падающего мяча | своя физика: платформы, коллизии, отскоки, `argparse` |
| `trex` | Бот для Chrome Dino | захват экрана через `mss`, калибровка игровой области, поиск препятствий |
| `kak_nibud` | Эксперименты с каналами | перестановки каналов BGR/RGB, наложение изображений |
| `ana_images`, `npy-images` | Данные | наборы `.npy`-массивов и изображений для работ |
| `sandbox` | Черновики и разовые скрипты | свёртка, гистограммы, признаки через `regionprops` |

## Установка

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Скрипты сами находят свои данные — запускать можно из любой директории:

```bash
python alphabet/main.py
python vector_recognition/main.py
python falling_ball/main.py
python aud_25_04/figures_classify.py
```

Часть работ требует окружения:

- `motion_detection`, `template_matching` — веб-камера;
- `trex` — запущенный Chrome с игрой Dino и права на захват экрана;
- `paper` — камера и ZeroMQ-поток;
- `balls`, `aud_25_04` — окно OpenCV с обработкой мыши (клик по объекту, `q` — выход).

## Как это выглядит

Классификатор символов (`alphabet`) разбирает картинку на связные компоненты и для каждой
строит набор признаков: число «дырок», полные вертикальные и горизонтальные линии, число заливов,
эксцентриситет, соотношение сторон. Дальше — дерево условий: два прокола и много вертикальных
линий — `B`, два прокола без линий — `8`, один прокол и высокая эксцентриситет — `0` и так далее.
Скрипт печатает распределение по классам и долю символов, которые не удалось отнести ни к одному.

В `vector_recognition` тот же подход превращён в метрический: 11 нормированных признаков
(площадь, центроид, периметр, дырки, линии, эксцентриситет, соотношение сторон, solidity,
горизонтальная симметрия) и ближайший эталон по евклидову расстоянию — по сути, примитивный
k-NN с одним соседом.

Самые «продуктовые» работы — `balls` и `falling_ball`: интерактивный трекер с кликом по цвету,
историей позиций и сохранением конфигурации, и симуляция с платформами и честной обработкой
коллизий.
